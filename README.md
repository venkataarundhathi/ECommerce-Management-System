# E-Commerce Management System for Electronic Devices

## Project Overview
A database management system designed to manage an electronic devices e-commerce platform.

## Technologies Used
- MySQL
- MySQL Workbench
- VS Code
- GitHub

## Main Features
- Customer management
- Product and category management
- Order management
- Payment management
- Inventory management
- Product search and suitability checking
- Automatic inventory updates

## Database Concepts
- 18 Database Tables
- Primary and Foreign Keys
- SQL Joins
- Stored Procedures
- Views
- Triggers
- Transactions
- CRUD Operations

## Project Files
- schema.sql
- procedures.sql
- views.sql
- triggers.sql
